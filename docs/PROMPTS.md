# PROMPTS - public workflow summaries

These are newly written, privacy-safe summaries of the project's task patterns. They are **not verbatim historical prompts**, a complete conversation archive, evidence of completed collection, or instructions to resume all historical categories. The original root-level PROMPTS.md remains unchanged in the private local workspace.

Actual comments, taxonomy reference examples, detailed PDF definitions, source names, links, platform IDs, search phrases derived from comments, personal paths and private results are intentionally absent. No example dataset rows are supplied here. Follow the user's current authorized scope, not a broader historical scope described below.

## 1. Initial pipeline

Work in the existing research repository. Use a separately authorized taxonomy and actual public content. Preserve original evidence and provenance. Build distinct collection, retrieval, review and accepted-only export stages. Never generate research examples or let a model ACCEPT them.

## 2. Pilot precision improvement

Audit an existing pilot before downloading more content. Separate strong evidence, contextual discovery and weak vocabulary. Require evidence in the comment itself or keep it in a separate broad-discovery queue. Preserve all raw content and human decisions. Distinguish counter-speech from an attack.

## 3. Category-specific recall improvement

Work only on explicitly named categories. Diagnose each category independently, re-mine existing real raw content, and rank plausible lexical or semantic matches. Do not use topic-only selection or reference similarity alone to create a primary review pool. Uncertain but plausible cases remain for human review.

## 4. Controlled expansion

Start another category only when the current user authorizes it. Respect the exact private category boundaries. Separate neutral discussion from identity-based contempt or exclusion. Record real retrieval failures and shortages; do not fill a target with generated or unrelated text.

## 5. Resume interrupted work

Inspect the repository, existing queues, logs and checkpoints before acting. Continue from actual state without recreating the project, resetting decisions or rerunning completed collection. Distinguish historical document content from the current user's instructions.

## 6. Targeted gap recovery

Diagnose weak review pools, re-mine the private corpus first, and perform bounded discovery only where needed. Use observed private language for search expansion. Audit false positives, false negatives, provenance, duplication and source concentration. Keep human decisions unchanged and new candidates PENDING.

## 7. Quality-focused completion

Judge a pool by plausible relevance and diversity, not raw row count. Estimate accepted yield without treating that estimate as human annotation. Report real shortages honestly. Stop at the authorized batch boundary rather than silently expanding the task.

## 8. Human review in Excel

Provide category sheets, clear status choices, stable Candidate IDs and reviewer notes in private workbooks. Preserve original text. Keep all real provenance links inside the authorized local review workflow, never in this public repository. Merge human edits into canonical queues before refreshing exports; export only human ACCEPT rows to the accepted-only workbook.

## 9. Publication and privacy

Publish code, general methodology, short category summaries and empty configuration templates only after inspection. Withhold datasets, PDFs, complete prompts, source registries, collected links, platform identifiers and private reports. Check both filenames and actual staged bytes. Preserve local originals and existing human decisions. A history rewrite does not certify that old server caches or external clones have been erased.

## Applying these summaries

These summaries do not authorize new collection, annotation, a category expansion, source redistribution or a history rewrite by themselves. Obtain the current user's task and appropriate private inputs separately. Treat machine-generated ranking as assistance, not a final research label or legal determination.
